What is an IME?

An IME (Input Method Editor) is already built into your phone and computer. You type in romaji (Latin letters) and it converts to Japanese characters automatically.

Example: type watashi → わたし → 私

How Romaji Input Works

Type the sound of each character in English letters:

a → あka → かsa → さ ta → たna → なha → は ma → まya → やra → ら wa → わshi → しchi → ち tsu → つnn → ん

Double consonants → small っ: kitte → きって (stamp)

Long vowels: ou → おう, uu → うう

Kana Keyboard (Mobile)

On phone keyboards, you can also use the flick keyboard: tap a consonant row (あ, か, さ…) and flick in a direction to choose the vowel. It's faster once you get used to it!

Setting Up Japanese Input

iPhone / iPad: Settings → General → Keyboard → Keyboards → Add → Japanese (Romaji or Kana). Switch with 🌐.
Android: Settings → System → Languages & input → Gboard → Languages → Add → Japanese. Switch with 🌐.
Windows: Settings → Time & Language → Add 日本語. Win+Space to switch, Alt+~ to toggle modes.
Mac: System Settings → Keyboard → Input Sources → + → Japanese (Romaji). Ctrl+Space to switch.

Tips for This App

In Type, Fill, and Full levels, type in Japanese characters. The romaji shown below each line is your pronunciation guide — type it and let your IME convert!

Don't worry about kanji at first — hiragana is always accepted.
